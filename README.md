# FG WMS — ระบบจัดการคลังสินค้าสำเร็จรูปของ BIO-COSLAB

FG WMS เป็นระบบจัดการคลังสินค้าสำเร็จรูปของ BIO-COSLAB ใช้ภาษา UI และแนวทางออกแบบร่วมกับ PK WMS: เมนูสีเข้ม ปุ่ม IBM Blue พื้นผิวสีขาว/เทา ตัวอักษร IBM Plex Sans Thai และแบบฟอร์ม/ตารางที่ใช้บนมือถือได้

**เว็บที่เผยแพร่:** https://fg-wms.vercel.app/

**ซอร์สโค้ด:** https://github.com/nk02388-cyber/FG-WMS

## เริ่มใช้งาน

รันผ่าน HTTP ด้วย Node.js:

```powershell
cd "C:\Users\ADMIN\Documents\Codex\2026-09-28\rm-wms\outputs\FG-WMS"
node server.js
```

จากนั้นเปิด `http://localhost:8000/`

## งานที่ใช้ได้

- ดู Dashboard ยอดคงเหลือ จำนวน SKU จำนวนชุดจัดเก็บ และชุดใกล้หมดอายุ
- รับเข้า FG โดยระบุ SKU, ชื่อสินค้า, Lot, จำนวน, หน่วย, ตำแหน่ง, รหัสชุด และวันผลิต/หมดอายุ
- ดูและค้นหาสต็อกตามสินค้า, Lot, พาเลต และตำแหน่ง
- เบิกจ่ายจากชุดจัดเก็บที่เลือก พร้อมป้องกันการเบิกเกินยอดและเบิกชุดที่หมดอายุ
- ย้ายทั้งชุด หรือแบ่งจำนวนไปยังรหัสชุดใหม่
- ตรวจนับและปรับยอด โดยเก็บยอดก่อนนับและส่วนต่างในประวัติ
- ค้นหาประวัติการรับ เบิก ย้าย และตรวจนับ
- ส่งออก/นำเข้าข้อมูล JSON เพื่อสำรองหรือย้ายเครื่อง

## ขอบเขตข้อมูล

ข้อมูลเริ่มต้นว่าง ไม่มีตัวเลขหรือสินค้าตัวอย่างที่แสดงเป็นข้อมูลจริง ระบบเก็บข้อมูลใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง ไม่มีบัญชีผู้ใช้, ฐานข้อมูลกลาง, การซิงค์ข้ามเครื่อง หรือการเชื่อม PK/RM WMS การนำเข้า JSON จะเขียนทับข้อมูล FG WMS ในเบราว์เซอร์นั้นหลังผู้ใช้ยืนยัน

Vercel deploy จากชุดไฟล์ static ที่ตรงกับ commit เริ่มต้นของ GitHub ปัจจุบันยังไม่ได้เชื่อม Git Integration จึงต้อง deploy ด้วยตนเองเมื่อแก้โค้ด; การ push ไป GitHub เพียงอย่างเดียวไม่อัปเดตเว็บ Vercel

หากต้องใช้หลายเครื่องหรือเชื่อมเมนู FG ใน BCL WMS ขั้นต่อไปคือกำหนดแหล่งข้อมูล FG, สิทธิ์ผู้ใช้, ฐานข้อมูลและวิธี deploy ก่อนเชื่อมต่อจริง อย่านำไฟล์ฐานข้อมูลหรือรหัสผ่านของ PK ไปใช้กับ FG โดยตรง
